# Online Ride-Hailing Service Point Optimization

A C++-based project that optimizes the placement of online ride-hailing (ojek online) service points using Brute Force and Greedy algorithms.

## Overview

This project focuses on finding the optimal placement of ride-hailing service points in a metropolitan area to minimize user waiting time and improve driver efficiency.

It was developed as part of a Data Structures course, applying algorithmic approaches to solve a real-world optimization problem.

## Problem Background

Efficient placement of service points is crucial in ride-hailing systems. Poor placement can lead to:

* Increased user waiting time
* Inefficient driver routing
* Reduced overall system performance

This project explores how algorithmic strategies can be used to determine the most effective service point locations.

## Approach

Two different algorithms are implemented and compared:

### Brute Force Algorithm

* Evaluates all possible combinations of service point placements
* Guarantees the optimal solution
* Computationally expensive but accurate

### Greedy Algorithm

* Selects the best local choice at each step
* Faster and more efficient
* May not always produce the global optimum

## Features

* Simulates placement of service points in a metropolitan area
* Compares results between Brute Force and Greedy approaches
* Evaluates efficiency in terms of distance or coverage
* Demonstrates trade-offs between accuracy and performance
